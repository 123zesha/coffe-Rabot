# Per-project folder structure

When a new video project is created, the system will automatically create
these subfolders inside `projects/<project-name>/`:

| Folder | Purpose |
|---|---|
| `script/` | Generated long-form script |
| `scenes/` | Scene-by-scene breakdown |
| `characters/` | Character definitions for consistency |
| `images/` | Generated images |
| `video_clips/` | Generated video clips |
| `audio/` | Voice-over audio |
| `subtitles/` | Subtitle files |
| `music/` | Background music and sound effects |
| `thumbnail/` | Thumbnail image(s) |
| `metadata/` | Title, description, tags |
| `final/` | Final rendered MP4 |

This is a reference only — the automation that creates these folders per
project is not implemented yet.
