# projects/

Each YouTube video project will get its own folder here, created
automatically, containing:

- `script/`
- `scenes/`
- `characters/`
- `images/`
- `video_clips/`
- `audio/`
- `subtitles/`
- `music/`
- `thumbnail/`
- `metadata/`
- `final/`

See `templates/project_folder_structure.md` for what each subfolder holds.
No project folders exist yet — this happens automatically once workflow
automation is built.
